I Attacked My Own SOC

A real attack from Kali, blocked by a FortiGate, detected by a free SIEM, and quarantined with one click.
The attack
A port scan and web exploits launched from Kali Linux.
The defense
FortiGate deny policies plus IPS on the only open port.
The detection
Every block lands on a Grafana wallboard within seconds.
The response
An alert on my PC asks: quarantine this IP? One click and it is cut off.
The Problem

Your Firewall Sees Everything. You Don't.

FortiGate logs every decision, but nobody watches a scrolling log table.
Logs nobody reads
A single port scan produces thousands of log lines per minute.
Silent denies
The implicit deny blocks traffic and logs nothing by default.
SIEMs cost money
Commercial SIEMs bill by data volume. A homelab can't justify that.

The Lab

Two Zones. One Firewall. No Way Out.

Kali lives in USERS, the SOC lives in SERVERS, and every packet between them crosses FGTQC01. Kali has no route to WAN.
zone USERS · VLAN_QC_40
Kali Linux at 192.168.40.3. No internet: a work-lab rule, enforced by a logged deny.
FGTQC01 · FortiOS 7.4
Zone-based policies on a port2 trunk. Admin PC comes in through port1 VIPs.
zone SERVERS · VLAN_QC_10
Alpine with Docker at 192.168.10.2: Vector, Loki, Grafana, ntfy and the responder.
The Data Flow

Syslog → Vector → Loki → Grafana

Four hops from a blocked packet to a red line on the wallboard.
FortiGate → UDP 514
Every allow, deny and IPS hit leaves as a syslog line.
Vector parses
Turns key=value text into JSON and tags a verdict.
Loki stores, Grafana shows
Loki indexes a few labels. Grafana queries it with LogQL.
The Secret Sauce

Every Log Gets a Verdict

Vector turns raw FortiOS text into JSON and labels each line blocked, detected or allowed.
blocked
A firewall deny, an IPS drop or an IPS reset.
detected
The IPS logged it, but the traffic was let through.
allowed
A normal session through an accept policy.
FortiGate Config

Only Port 80 Gets In

Four policies, one IPS sensor, and a deny rule that logs everything else.
Policy 3 · Kali_To_SOC_Web
HTTP to one host only, inspected by the SOC-Demo-IPS sensor.
Policy 101 · Kali_To_Servers_Deny
An explicit deny with logging on. This is what feeds the wallboard.
Policy 102 · Kali_To_WAN_Deny
Kali never reaches the internet. Every attempt is logged.
Syslog to 192.168.10.2
Default format over UDP 514, sourced from 192.168.10.1.
Deploy

One Script on Alpine

setup.sh installs Docker, starts five containers, wires the FortiGate token and tests everything for you.
Installs only what's missing
Docker, the compose plugin and curl, tracked for a clean rollback.
Generates every secret
Grafana password, ntfy topic and link-signing key. It only asks for the FortiGate token.
Self-tests the pipeline
Syslog into Loki, the responder, and a test notification on your PC.
The Demo

Three Phases of Attack

A scripted campaign from Kali: recon, a port scan, then web exploits on the one open port.
1 · Recon
A ping sweep of VLAN 10, denied and logged by policy 3.
2 · Port scan
A thousand TCP ports. Only port 80 answers.
3 · Web attacks
SQL injection, path traversal, Log4Shell and Nikto. The IPS drops them.
Lab only · no WAN
The script refuses targets outside 192.168.10.0/24, and Kali has no internet at all.
Detection Engineering

Alerts That Fire Themselves

Three Grafana alert rules turn the wallboard into a detection system.
Port scan · MITRE T1046
More than 20 distinct denied ports from one source in 60 seconds.
Web attack · MITRE T1190
Any IPS signature match against the dashboard host.
Log feed silent
No FortiGate logs at all for five minutes.
Routed to the responder
Every alert goes to a webhook that never leaves the Docker network.
Detect → Approve → Quarantine

One Click. Attacker Gone.

A small Python responder turns the Grafana alert into ntfy buttons and drives the FortiGate REST API.
Approve or automatic
Default: buttons on my PC. Switch to auto and it bans at once, still sending both alerts.
Policy 100 at the top
The responder adds Q-192.168.40.3 to SOC-Quarantine. Every new connection is denied.
Released on a timer
After 15 minutes, or Release now, the object is removed and ntfy says released.
Safety rails
Allowlist, signed one-time links, and an API token that can only touch address objects.
